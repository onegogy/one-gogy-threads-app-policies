Политика конфиденциальности

Приложение "one_gogy threads connector" — личный инструмент для публикации постов и ответов на комментарии в Threads-аккаунте @one_gogy. Приложением пользуется только его владелец, оно не предназначено для сторонних пользователей.

Какие данные обрабатываются

Приложение работает с access-токеном Threads API и данными, полученными через Threads API от имени владельца аккаунта: текстами постов, комментариями и базовой статистикой (охваты, лайки, ответы). Все данные хранятся локально на устройстве владельца и не передаются третьим лицам.

Telegram-бот

Для одобрения черновиков постов используется частный Telegram-бот, доступный только владельцу аккаунта. Сообщения бота не логируются и не передаются за пределы этого личного использования.

Хранение и удаление данных

Токены доступа хранятся локально и могут быть отозваны владельцем в любой момент через настройки приложения в Meta for Developers. Чтобы удалить данные, свяжитесь с контактом ниже.
